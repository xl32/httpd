  *) mod_http3: Linux: with ListenCoresBucketsRatio, connection migration
     works. Byte 0 of each server connection ID holds the bucket number, and
     an SK_REUSEPORT eBPF program sends each packet to the socket of that
     bucket. The server no longer sends disable_active_migration. If the
     program cannot load (kernel before 4.19, no CAP_BPF, SELinux, seccomp), a
     warning gives the reason and the server keeps sending
     disable_active_migration.
